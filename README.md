<h1>Active Directory Home Lab</h1>

 

<h2>Description</h2>
Project consists of a simple excercise where I used a VirtualBox to setup a basic home lab and went through the steps to Add Users w/PowerShell.
<br />


<h2>Languages and Utilities Used</h2>

- <b>PowerShell</b> 
- <b>VirtualBox</b>

<h2>Environments Used </h2>

- <b>Windows 10</b> (21H2)
